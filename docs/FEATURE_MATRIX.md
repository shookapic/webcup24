- **D2** Accept-Encoding with q=0 is ignored (server.mjs serveFile; low severity).
- **D3** a failed refresh replaces the request history (citizen) or message list (staff) by the error text, losing the last good data (public/app.js loadMessages catch; same on the dashboard to-do list).
- **D4** a failed staff status change leaves the selector showing the unsaved state and reports through a modal alert() (public/app.js).
